# Advanced Solar Panels: Refactored

Forge addon project for Minecraft 1.20.1 and IndustrialCraft 2: Refactored.

## Dependencies

- Minecraft 1.20.1
- Forge 47.4.20
- IndustrialCraft 2: Refactored 2.10.34-ex120, imported from `libs/ic2-forge-2.10.34-ex120.jar`
- JEI 15.20.0.130, optional integration
- Jade 11.13.2+forge, optional integration

## Build

```bash
sh gradlew build
```

The built mod jar is written to `build/libs/`.
